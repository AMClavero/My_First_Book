# Resolver ecuaciones de segundo grado

En este capítulo de ejemplo veremos cómo resolver ecuaciones cuadráticas de la forma

$$ax^2 + bx + c = 0$$

y aplicaremos la fórmula general. Suponiendo $a \ne 0$, las soluciones son:

$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

Ejemplo rápido:

- Para $x^2 - 3x + 2 = 0$ tenemos $a=1,b=-3,c=2$ → $x=1$ o $x=2$.

Pequeña explicación paso a paso y enlaces a recursos.
